# UP 2027 Party Symbol Pack

Party symbols used by the Top Analytica UP 2027 interface.

Verified against the Election Commission / UP State Election Commission references and the supplied 2022 UP election source material. The symbol identities covered here include:
- BJP — Lotus
- SP — Bicycle
- BSP — Elephant
- INC — Hand
- RLD — Hand Pump
- SBSP — Walking Stick
- ADS / AD(S) — Cup and Saucer
- NISHAD — Plate Full of Food (Bhojan Bhari Thali)
- JDL / JD(L) — Saw
- AD(K) — Envelope
- JD(U) — Arrow
- AAP — Broom
- IND — no single party symbol; candidate-specific symbol, so no fixed image is assigned.

The data layer is unchanged. These assets are presentation-only.


## BJP lotus replacement
The BJP asset `bjp-lotus.svg` has been replaced with a ballot/election-symbol style lotus based on the Election Commission of India reserved-symbol reference (BJP — Lotus). No project data files were changed.
