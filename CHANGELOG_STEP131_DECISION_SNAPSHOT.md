# STEP131 — VANDIRA Decision Snapshot & Brief Actions

## Objective
Extend the AI Answer → Evidence → Intelligence Brief → Recommended Action flow with a compact Decision Snapshot layer.

## Changes
- Added a Decision Snapshot card after the Intelligence Brief.
- Snapshot is derived only from the current AI response context: AC, party, route layer, confidence, freshness, answer/readout, key points and data gaps.
- Added local-first Copy action for the decision record.
- Added local-first Save action using `vandiraDecisionSnapshotsV1`, capped at 25 records.
- No election data, calculations, canonical records or source values were modified.
- Existing Evidence, Intelligence Brief, Recommended Action and Next Intelligence layers remain intact.

## Guardrails
- No new political facts are generated by the snapshot layer.
- Saved snapshots are client-local and are not presented as server-authoritative records.
- Snapshot explicitly states that it is based on available evidence and current answer context.
