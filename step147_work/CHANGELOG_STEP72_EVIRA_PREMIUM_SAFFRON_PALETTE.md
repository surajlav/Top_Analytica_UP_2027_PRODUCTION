# STEP72 — EVIRA Premium Saffron / Ink / White Palette

Implemented on top of STEP71.

## Visual direction
- Primary accent moved from the previous warm gold/orange mix to a stronger saffron: `#C87924`.
- Secondary gold restrained to micro-details only: `#A88B5A`.
- Primary typography moved to deep black/ink: `#111111`.
- Workspace background is clean white with a very subtle warm-ivory transition only where useful.
- Borders use a restrained warm neutral rather than blue/grey UI chrome.
- EVIRA badge, send button and active accents use saffron.
- Headings, brand wordmark, pencil and menu controls use black/ink.
- Gold is not used for large fills, gradients or repeated decorative elements.

## Functional preservation
- STEP71 ChatGPT-style mobile header/composer retained.
- Pencil new-chat control retained.
- Three-dot menu and visible overflow behavior retained.
- Hindi-first / automatic multilingual architecture retained.
- History and profile retained.
- No election, constituency, booth, Form 20 or historical data values were modified.
